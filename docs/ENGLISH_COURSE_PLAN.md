# Personal English Practice Plan

This is a proposed progression, not a claim about completed learning. EnPet shows actual progress only when a valid session record exists.

## Learner context

Simons is a Chinese speaker and AI engineer at ByteDance. Regular topics include agent development, harnesses, long-running tasks, Transformer models, and AI applications. Personal-interest scenarios can include *Interstellar*.

## Stages

| Stage | Practice outcome | Example units |
| --- | --- | --- |
| 1. Clear project updates | Explain current work, contributions, blockers, and results in connected sentences. | Project updates; describing impact; working with another team |
| 2. Natural technical discussion | Explain design choices, agent workflows, harness behavior, and trade-offs. | Agent development; long-running tasks; model evaluation |
| 3. Research and opinions | Summarize a Transformer or AI application idea, compare options, and support an opinion. | Explaining an architecture; comparing approaches; proposing an experiment |
| 4. Flexible conversation | Clarify, ask follow-up questions, narrate, and sustain a conversation on work or interests. | Team discussion; product idea; *Interstellar* scene or theme |

## Unit rhythm

1. Begin with a short scenario and a few target expressions from the local vocabulary plus useful new expressions.
2. Let the learner answer in their own words.
3. Select at most one to three high-value corrections. First offer a light hint; give the correction if needed.
4. Ask the learner to retry or restate the idea with the corrected expression.
5. Save the original response, correction, hint level, retries, evidence, and next focus before moving to another independent unit.

## Progress rules

Do not use a daily streak, guessed completion percentage, or number of turns as a learning result. A completed unit is a unit with a `complete` record. A word or phrase is mastered only when the evidence rule in `CODEX_PRACTICE_WORKFLOW.md` is met. Keep recurring errors in the next-focus list until later sessions show repeated retrieval on different dates. Use mastered items for occasional spot checks rather than ordinary daily focus.
